## Overview
**SIEM** — is a comprehensive system that provides centralized processing, monitoring, and analysis of security events and information in computer systems and networks. It is a comprehensive approach to security management that combines Security Information Management (**SIM**) and Security Event Management (**SEM**) into a single solution:

- **SIM** involves the collection, storage, and analysis of security-related data from various sources, providing a centralized view of an organization's security posture.

- **SEM** focuses on real-time monitoring and correlation of security events to detect and respond to potential threats promptly.
### Purpose
To provide centralized monitoring and analysis of security events to detect and respond to potential security threats.
### Benefits
- Real-time monitoring.
- Centralized collection and analysis of log data.
- Detection of anomalies and potential security threats.
- Automation of incident detection and response.

### Key responsibilities

1. **Centralized Visibility**:
	    SIEM provides a centralized platform for collecting, storing, and analyzing security data from diverse sources, offering a unified view of an organization's security posture.
	    
2. **Detection of Security Incidents**:
	    SIEM tools monitor events in real time, enabling the detection of security incidents and suspicious activities by correlating data from multiple sources.
	    
3. **Incident Response and Forensics**:
	    SIEM facilitates efficient incident response by providing detailed insights into security incidents. It aids in forensic analysis to understand the scope and impact of security events.
	    
4. **Compliance Management:**
	    SIEM supports compliance by monitoring and reporting on activities that align with regulatory requirements. It helps organizations adhere to standards such as GDPR, HIPAA, and PCI DSS.
	    
5. **Threat Intelligence Integration**:
	    SIEM tools integrate with threat intelligence feeds, enriching security data with information about known threats and vulnerabilities. This integration enhances the ability to identify and respond to emerging threats.
	        
6. **Log Management and Retention:**
	    SIEM handles the collection and management of logs generated by various systems and applications, ensuring the retention of historical data for analysis and compliance purposes.
	    
### Representation

1. [[Splunk]] is a popular SIEM tool that is known for its powerful search and analytics capabilities. It can collect, store, and analyze data from a wide variety of sources, including logs, events, and metrics.
2. [[QRadar]] is a SIEM tool from IBM that is known for its strong correlation and threat intelligence capabilities. It can collect, store, and analyze data from a wide variety of sources, including logs, events, and metrics.
3. [[ELK Stack]] is an open-source SIEM tool that is based on three open-source tools: `Elasticsearch`, `Logstash`, and `Kibana`. `Elasticsearch` is a search and analytics engine, `Logstash` is a log collection tool, and `Kibana` is a data visualization tool.

## Concept
### Core components

#### Log Management

- **Importance of Log Collection and Analysis**:
	- Log data is a valuable source of information for *understanding system activities* and *detecting security incidents*.
	  
	- Log management involves *collecting*, *storing*, and *analyzing* logs to gain insights into the security posture of an organization.
	  
	- Logs provide a *historical record* that aids in forensic analysis, troubleshooting, and compliance adherence.
	  
- **Types of Logs (Security, Application, System):**
	- **Security Logs**: Capture events related to security, such as authentication attempts, firewall activities, and intrusion detection alerts.
	  
	- **Application Logs**: Record events generated by applications, helping in identifying issues, errors, and usage patterns.
	  
	- **System Logs**: Document system-level activities, including hardware and software events, system errors, and resource usage.
	  
- **Log Normalization and Parsing**:
	- **Log Normalization:** The process of transforming diverse log formats into a common, normalized format for easier analysis.
	  
	- **Parsing**: Involves breaking down log entries into structured fields, allowing for efficient querying and correlation.
	  
	- **Standardizing logs**: ensures consistency and facilitates correlation of events across different sources.
	  

#### Security Event Management (**SEM**)

- **Real-Time Monitoring and Correlation:**
	- SEM involves monitoring events in real-time to identify potential security incidents.
	  
	- Correlation refers to the analysis of multiple events to determine if they collectively indicate a security threat.
	  
	- Real-time monitoring enables prompt response to emerging security issues.
	  
- **Detection of Security Events:**
	- SEM systems employ predefined rules and behavioral analysis to detect abnormal or suspicious activities.
	  
	- ***Signature-based*** detection identifies known patterns of malicious behavior.
	  
	- ***Anomaly-based*** detection looks for deviations from normal behavior.
	  
- **Alerting and Notification Mechanisms:**
	- When a potential security event is detected, the SEM system generates alerts.
	  
	- Alerts can trigger notifications via email, SMS, or integration with incident response systems.
	  
	- Effective alerting ensures that security teams can respond promptly to mitigate risks.

#### Security Information Management (**SIM**)

- **Storage and Analysis of Security-Related Data:**
	- SIM focuses on collecting, storing, and analyzing security-related data from various sources.
	  
	- Centralized storage facilitates efficient retrieval and analysis of historical security data.
	  
	- Storage may involve long-term archiving for compliance purposes.
	  
- **Historical Analysis and Reporting:**
	- Historical analysis allows security teams to review past events and identify patterns or trends.
	  
	- Reporting functionalities provide insights into security metrics, compliance status, and potential areas of improvement.
	  
	- Historical data is crucial for post-incident analysis and forensic investigations.
	  
- **Compliance Monitoring and Reporting:**
	- SIM plays a key role in ensuring compliance with regulatory requirements.
	  
	- Automated reporting features assist in generating compliance reports for audits.
	  
	- Continuous monitoring helps organizations demonstrate adherence to security standards.
