>[!quote]+ The injection
>`'or "1"="1" --`
>##### Syntax
>- `'` — character ending a value. Speaking about python, some developers might still use `f-strings` or a simple concatenation to forward a value to the query (**The safe approach:** parametrized query). By doing so, they allow basic SQL syntax attack
>- `"1"="1"` — is a statement that is always true
>- `--` — SQL comment syntax, so that everything will be ignored until the `;` character

**Decision reasoning:**

- _The first option_: uses parametrized login input, but not a parametrized password one. Hashes the password
    
- _The second option_: uses parametrized login and password input. Hashes the password
    
- _Third option_: uses parametrized login and password input. Does not provide password hashing
    
- _The fourth option_: attempts to implement a custom sqli protection which is a horrible decision from the get go (The tremendous amount of nuances, unsupportable, demands time to develop properly without any obvious reason, as the standard approaches are still available and reliable).
