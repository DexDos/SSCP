### TOTP
To leverage the secret obtained we need to brake down what is a [[TOTP]]:

**TOTP** stands for Time-based One-Time Password. It is a security algorithm that creates a temporary, unique 6-digit code changing every 30 seconds. It serves as a core method for two-factor authentication (2FA), used by apps like Google Authenticator to verify your identity safely during login.

The exact configurations might differ depending on the platform (4, 6, 8 digits; hashing algorithm etc.). But essentially they are quite common and even similar:

#### How does it work

1. At first we have to state that there are two sides: a *user* and a *server*. Those participants must have the UNIX-time calculating chip which outputs with an identical number no-matter where are they located. So that both sides have everything essential for TOTP calculation.
   
2. The validation process is identical on both sides, so we will show the User's one.
   
3. User divides UTC by period, converting the output to be a **Big Endian** hex; he converts the secret from the format it was stored in to binary simultaneously.
   
4. Then the user calculates an HMAC based on the algorithm specified (usually **SHA-1**).
   
5. The digest then consists of 20 bytes (SHA-1). The last half-byte is being cut to define the **offset**. Since the last byte is incomplete, the 19-th byte (`20 bytes = [0, 1, ..., 19]`) will not take place in the further calculation (`4 bits` maximum value is 15 ( $1111_2=8+4+2+1=15_{10}$ ) ) to prevent **Buffer Overflow**-like incidents. The value of the offset defines the byte which will be starting the 4-byte output.
   
6. The final 4 bytes are forcefully casted to a positive value by `four_bytes AND 0x7FFFFFFF` operation, which sets the first bit to `0`. It then gets divided by a module of N — the desired number of digits for TOTP. The output is the TOTP.

So the entire procedure would be:

Pseudocode example:
```
function generate_totp(secret_base32, algo="SHA1", period=30, digits=6):
    // 1. Decoding secret
    secret_bytes = base32_decode(secret_base32)
    
    // 2. Measuting time chunks (Counter)
    time_now = current_unix_timestamp()
    counter = floor(time_now / period)
    counter_bytes = pack_uint64_big_endian(counter) // 8 bytes
    
    // 3. Calculating HMAC
    hmac_hash = compute_hmac(algo, secret_bytes, counter_bytes)
    
    // 4. Dynamic Truncation
    offset = hmac_hash[last_byte_index] AND 0x0F
    
    four_bytes = hmac_hash[offset : offset + 4]
    
    // Turning 4 bytes into 32-byte integer and truncating the negative sign 
    unsigned_int32 = (four_bytes AND 0x7FFFFFFF)
    
    // 5. Calculating a MOD to get N digits
    otp_code = unsigned_int32 MOD (10 ^ digits)
    
    // Returning with zeroes ahead
    return pad_left_with_zeros(otp_code, digits)
```

## Developing an TOTP Generator

Of course, we may also use online **TOTP Generators** like [TOTP Token Generator](https://totp.danhersam.com/). But it is not that fun and won't allow us to understand the subtle shades of the technology. We love coding btw, so this would be a self-assigned challenge :D

### The generator program code
The code of a `bash` program:

```bash
#!/usr/bin/env bash

RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
CYAN='\033[0;36m'
BOLD='\033[1m'
NC='\033[0m' # No Color

# Default TOTP parameters
SECRET=""
ALGO="sha1"
DIGITS="6"
PERIOD="30"

show_ascii_art() {
    echo -e "${CYAN}"
    echo '  ████████╗██████╗ ████████╗██████╗ '
    echo '  ╚══██╔══╝██╔══██╗╚══██╔══╝██╔══██╗'
    echo '     ██║   ██║  ██║   ██║   ██████╔╝'
    echo '     ██║   ██║  ██║   ██║   ██╔═══╝ '
    echo '     ██║   ╚██████╔╝   ██║   ██║     '
    echo '     ╚═╝    ╚═════╝    ╚═╝   ╚═╝     '
    echo -e "      ${YELLOW}${BOLD}T O T P   G E N E R A T O R${NC}\n"
}

# OathTool dependency verification
check_dependency() {
    if ! command -v oathtool &> /dev/null; then
        echo -e "${RED}Error: 'oathtool' utility is not installed.${NC}"
        echo "Please install it using your package manager:"
        echo "  - Debian/Ubuntu: sudo apt install oathtool"
        echo "  - Arch Linux:    sudo pacman -S oathtool"
        echo "  - macOS:         brew install oathtool"
        exit 1
    fi
}

# Base32 secret input and sanitation
set_secret() {
    echo -e "\n${CYAN}--- Base32 Secret Configuration ---${NC}"
    read -rp "Enter Base32 secret key: " raw_secret
    # Trim spaces and convert to uppercase
    SECRET=$(echo "$raw_secret" | tr -d ' ' | tr 'a-z' 'A-Z')
    if [[ -z "$SECRET" ]]; then
        echo -e "${RED}Secret key cannot be empty!${NC}"
    else
        echo -e "${GREEN}Secret successfully saved.${NC}"
    fi
    sleep 1
}

# HMAC
set_algo() {
    echo -e "\n${CYAN}--- Select Hashing Algorithm ---${NC}"
    echo "1) SHA1 (Default)"
    echo "2) SHA256"
    echo "3) SHA512"
    read -rp "Your choice [1-3]: " choice
    case $choice in
        1|"") ALGO="sha1" ;;
        2)    ALGO="sha256" ;;
        3)    ALGO="sha512" ;;
        *)    echo -e "${RED}Invalid selection.${NC}"; sleep 1; return ;;
    esac
    echo -e "${GREEN}Algorithm set to: ${ALGO^^}${NC}"
    sleep 1
}

# time period
set_digits() {
    echo -e "\n${CYAN}--- Select Code Length ---${NC}"
    echo "1) 6 digits (Default)"
    echo "2) 4 digits"
    echo "3) 8 digits"
    read -rp "Your choice [1-3]: " choice
    case $choice in
        1|"") DIGITS="6" ;;
        2)    DIGITS="4" ;;
        3)    DIGITS="8" ;;
        *)    echo -e "${RED}Invalid selection.${NC}"; sleep 1; return ;;
    esac
    echo -e "${GREEN}Code length set to: ${DIGITS}${NC}"
    sleep 1
}

set_period() {
    echo -e "\n${CYAN}--- Configure Refresh Period ---${NC}"
    echo "1) 30 seconds (Standard)"
    echo "2) 60 seconds"
    echo "3) Custom period"
    read -rp "Your choice [1-3]: " choice
    case $choice in
        1|"") PERIOD="30" ;;
        2)    PERIOD="60" ;;
        3) 
            read -rp "Enter custom period in seconds: " custom_period
            if [[ "$custom_period" =~ ^[0-9]+$ ]] && [ "$custom_period" -gt 0 ]; then
                PERIOD="$custom_period"
            else
                echo -e "${RED}Invalid number!${NC}"
                sleep 1
                return
            fi
            ;;
        *) echo -e "${RED}Invalid selection.${NC}"; sleep 1; return ;;
    esac
    echo -e "${GREEN}Refresh period set to: ${PERIOD} sec.${NC}"
    sleep 1
}

get_totp_code() {
    oathtool --totp="$ALGO" --digits="$DIGITS" --time-step-size="${PERIOD}s" -b "$SECRET" 2>/dev/null
}

generate_once() {
    if [[ -z "$SECRET" ]]; then
        echo -e "\n${RED}Error: Secret key is not set!${NC}"
        read -rp "Press Enter to continue..."
        return
    fi

    local code
    code=$(get_totp_code)

    if [[ $? -ne 0 ]]; then
        echo -e "\n${RED}Generation error! Please verify your Base32 secret key.${NC}"
    else
        local now=$(date +%s)
        local remaining=$(( PERIOD - (now % PERIOD) ))
        echo -e "\n========================================"
        echo -e " Current TOTP: ${BOLD}${GREEN}${code}${NC}"
        echo -e " Remaining time: ${YELLOW}${remaining} sec.${NC}"
        echo -e "========================================"
    fi
    read -rp "Press Enter to return to menu..."
}

live_mode() {
    if [[ -z "$SECRET" ]]; then
        echo -e "\n${RED}Error: Secret key is not set!${NC}"
        read -rp "Press Enter to continue..."
        return
    fi

    clear
    show_ascii_art
    echo -e "${CYAN}=== Real-Time Monitor Mode (Press Ctrl+C to stop) ===${NC}\n"
    
    # Catch Ctrl+C to safely return to main menu
    trap 'trap - INT; return' INT

    while true; do
        local now=$(date +%s)
        local remaining=$(( PERIOD - (now % PERIOD) ))
        local code
        code=$(get_totp_code)

        if [[ $? -ne 0 ]]; then
            echo -e "\n${RED}Failed to generate TOTP. Check secret key format.${NC}"
            break
        fi

        printf "\r${BOLD}TOTP Code (%s digits): ${GREEN}%s${NC} | Refreshing in: ${YELLOW}%2d s${NC} " "$DIGITS" "$code" "$remaining"
        sleep 1
    done
    
    trap - INT
}

show_menu() {
    clear
    show_ascii_art
    
    if [[ -z "$SECRET" ]]; then
        echo -e " Secret:     ${RED}[NOT SET]${NC}"
    else
        local masked_secret="${SECRET:0:4}...${SECRET:-4}"
        echo -e " Secret:     ${GREEN}${masked_secret}${NC}"
    fi
    echo -e " Algorithm:  ${YELLOW}${ALGO^^}${NC}"
    echo -e " Digits:     ${YELLOW}${DIGITS} digits${NC}"
    echo -e " Period:     ${YELLOW}${PERIOD} seconds${NC}"
    echo -e "${CYAN}----------------------------------------${NC}"
    echo " 1) Set/Change Base32 Secret"
    echo " 2) Change Hashing Algorithm (SHA1 / SHA256 / SHA512)"
    echo " 3) Change Code Length (4 / 6 / 8)"
    echo " 4) Change Refresh Period"
    echo -e "${CYAN}----------------------------------------${NC}"
    echo -e " 5) ${BOLD}Generate Single Code${NC}"
    echo -e " 6) ${GREEN}${BOLD}Start Real-Time Generator${NC}"
    echo -e " 0) Exit"
    echo -e "${CYAN}========================================${NC}"
}

main() {
    check_dependency

    while true; do
        show_menu
        read -rp "Select an option [0-6]: " choice
        case $choice in
            1) set_secret ;;
            2) set_algo ;;
            3) set_digits ;;
            4) set_period ;;
            5) generate_once ;;
            6) live_mode ;;
            7) echo -e "\nGoodbye!"; exit 0 ;;
            *) echo -e "${RED}Invalid option!${NC}"; sleep 1 ;;
        esac
    done
}

main
```

## Ways to mitigate the risk and secure the attack vector

- Ensure the TOTP secrets are stored encrypted with secure ciphers and reliable keys
- Ensure backend input sanitation to prevent SQLI. Move the TOTP validation logic to the internal node with it's own secret retrieving mechanism so that any SQL queries to publicly available endpoints could not have access to any keys stored.
