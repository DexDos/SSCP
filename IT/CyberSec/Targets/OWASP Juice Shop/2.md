> [!question]- `<iframe>` code
> An **`<iframe>` (Inline Frame) tag** is used in HTML to embed another HTML document or external content directly inside the current webpage. It creates a nested browsing context, acting like a window that lets users view and interact with external media, maps, or pages without leaving your site. 
> #### How does it work
> `<iframe src="javascript:alert('xss')">`
> `<iframe>` embeds the code into the page DOM
> `src="javascript:..."` attempts to execute JS instead of reaching for a remote resource
>  `alert('xss')` calls an alert window as a proof of concept that the JS execution is performed
