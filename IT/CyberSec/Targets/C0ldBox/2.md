# Preparation
## The target
Make sure the target machine runs properly.

## The attack box
**The machine used:** [[Kali Linux]]
# Reconnaissance
The step which is aimed on gaining initial information about versatile architectural details about the target: software, hardware, versions, key stuff and other data which is meant to be converted to a number of **attack vectors**.
## Passive scanning
Scanning the target passively using **Shodan**, DNS-queries and so on. 

## Active scanning
Scanning the target's infrastructure directly. 

# Gaining access
This step is meant to acquire credentials, thus to gain a direct and authorized access to the target machine.

# Privilege escalation 
Once retrieved access to the shell or whatever, this step is meant to scale our internal capabilities, usually by using versatile forensic techniques.

# Persistence
This step is typically intended to establish a way to subtly restore access to the target's machine shell (primarily the root shell).
